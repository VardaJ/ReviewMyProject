# Welcome to Review My Project

## Project info

This is a web application that streamlines project submission, review, and approval by enabling students to upload projects and request appointments, while teachers review, approve, and provide feedback, ensuring efficient collaboration.

## How can I edit this code?

**Use your preferred IDE**

The only requirement is having Node.js & npm installed 

Follow these steps:

```sh
# Step 1: Extract the ZIP file into a folder of your choice.

# Step 2: Open the extracted folder in any code editor (e.g., VS Code).

# Step 3: Open the terminal and run the following commands:
cd backend
node server.js

# Step 4: In a new terminal window or tab, run the following command from the project root:
npm run dev

# Step 5: If the web page doesn't open automatically, copy and open the URL shown in the terminal (e.g., http://localhost:3000).
```
